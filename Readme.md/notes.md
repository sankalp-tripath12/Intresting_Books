# 📖 How I Study Each Book

For every book, the goal is to understand the material rather than simply finish the pages.

### 1. Overview

Before starting a book, understand:

* What the book is about
* Why it is important
* What problems it tries to solve
* What knowledge can be gained from it

### 2. Chapter-by-Chapter Learning

Each chapter is studied carefully.

Notes focus on:

* Important concepts
* Definitions
* Explanations
* Examples
* Key ideas
* Practical applications
* Important lessons

### 3. Connect Concepts

Whenever possible, concepts are connected with:

```text
Concept
   ↓
Example
   ↓
Practical Use
   ↓
Connection with Other Concepts
   ↓
Real-World Application
```

### 4. Apply What I Learn

Knowledge becomes more useful when it is applied.

Depending on the book, this may involve:

* Coding
* DSA problems
* Small projects
* Experiments
* Mathematical exercises
* System design
* ML implementations
